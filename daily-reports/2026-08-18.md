### 学到了什么

- git 全流程实操：`init / add / commit / remote add / fetch / push / reset --hard / set-upstream / set-url`
- GitHub noreply 邮箱可以隐藏真实邮箱；仓库名不能包含中文；创建空仓库时勾选 README 会导致推送冲突
- 本地文件副本会过时：发现不一致时应先对比，再决定以谁为准
- GitHub 仓库转移 API 与组织归属；凭据（credential）与权限范围（scopes）的概念——不同操作需要不同权限，例如删除仓库需要 `delete_repo`
- 项目级 command（`.claude/commands/`）与用户级 skill（`~/.claude/skills/`）的区别
- 技能文件（SKILL.md）的写法：命令要静态可分析（避免 `!` 前缀、避免 `$(...)` 命令替换），否则会被权限系统拒绝
