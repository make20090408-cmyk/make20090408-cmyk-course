# /report-today — 每日汇报

汇总今天的工作，生成日报并保存到本仓库的 `daily-reports/` 目录。

## 执行步骤

1. **收集工作数据**：
   - 分别查看 `手写数字/` 和 `game/` 两个子仓库今天的 git 提交记录（`git log --since="今天 00:00" --oneline`）
   - 查看今天修改或新增的文件（`git status`、`git diff --stat`）
   - 如果今天没有提交，检查工作区未提交的变更，也算作今天的工作

2. **询问用户补充**：基于收集到的数据列出今天的活动，询问用户是否有遗漏或补充（如课程学习、阅读、思考、调试过程等 git 里看不到的内容）。

3. **生成日报**，固定四部分结构：
   - **今天做了或学到了什么**
   - **遇到了或发现了什么问题**
   - **明天准备做什么**
   - **AI 从旁观视角给出的评价和建议**

4. **保存**：写入 `daily-reports/YYYY-MM-DD.md`（若文件已存在，询问用户是覆盖还是合并）。

5. **提交**：在根目录 `git add daily-reports/ && git commit -m "添加 YYYY-MM-DD 日报"`。

## 注意

- 数据以 git 记录为准，用户口述只作补充
- AI 评价部分要具体、有依据，引用当天实际的工作内容，不要空泛套话
- 日报用中文撰写
